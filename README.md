

# 💪 FitMetrics – Smart Workout Tracking App

FitMetrics is a modern Flutter-based workout tracking application designed to help users build consistent fitness habits, track progress, and manage personalized workout routines with a clean and intuitive user experience.

The app combines secure authentication, routine planning, exercise management, local offline storage, and performance tracking into a single fitness platform.

# ⚡ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/fitmetrics.git
```

---

## 2️⃣ Install Dependencies

```bash
flutter pub get
```

---

## 3️⃣ Run Application

```bash
flutter run
```

---

# 📦 Build APK

```bash
flutter build apk --release
```

Generated APK location:

```plaintext
build/app/outputs/flutter-apk/app-release.apk
```
